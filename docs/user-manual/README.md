# Manual de Usuario de Neuro Trader Journal

Este manual explica la plataforma desde el punto de vista del usuario. Describe para qué sirve cada área, cómo completar las tareas principales, cómo interpretar la información y qué hacer cuando faltan datos.

No incluye instrucciones de programación, configuración interna ni procesos administrativos de la empresa.

## Selecciona tu idioma

- [Manual en español](./es/overview.md)
- [User Manual in English](./en/overview.md)

## Cómo encontrar una respuesta

1. Abre el Centro de Ayuda desde la plataforma.
2. Selecciona el tema relacionado con tu pregunta.
3. Expande la sección que necesitas.
4. Si todavía tienes dudas, abre **Guía Neuro** con el botón flotante del cerebro.

Guía Neuro puede explicarte el manual, la página que estás viendo y, cuando sea relevante, un resumen de tus propios resultados. No sustituye al Coach Empresarial IA ni ofrece instrucciones para comprar o vender instrumentos financieros.

## Contenido principal

- Primeros pasos y configuración de cuenta
- Centro Empresarial y widgets
